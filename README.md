# 🤖 Jarvis - Virtual AI Assistant

An intelligent voice-controlled desktop assistant built with Python. Jarvis automates routine desktop tasks, processes speech input, performs web queries, and responds naturally using advanced AI models.

---

## ✨ Features

- 🎙️ **Speech-to-Text & Text-to-Speech:** Seamless voice interaction and natural vocal responses.
- ⚡ **Desktop Automation:** Automates application launching, system controls, and everyday tasks.
- 🔍 **Real-Time Search:** Performs online information retrieval and summarization.
- 🎨 **Image Generation:** Generates images via AI API integrations.
- 🖥️ **Interactive GUI:** Modern frontend interface for status updates and user interaction.

---

## 🛠️ Tech Stack & Libraries

- **Language:** Python
- **Key Modules:** SpeechRecognition, pyttsx3, GUI components, Automation scripts
- **AI / APIs:** Cohere, Groq, Tavily, Hugging Face

---

## 🚀 Setup & Installation

### 1. Clone the Repository
```bash
git clone [https://github.com/sneha-barad11/Jarvis-Virtual-Assistant.git](https://github.com/sneha-barad11/Jarvis-Virtual-Assistant.git)
cd Jarvis-Virtual-Assistant
2. Create and Activate Virtual Environment
Bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
3. Install Dependencies
Bash
pip install -r Requirements.txt
4. Configure Environment Variables
Create a .env file in the root directory and add your API keys:

Code snippet
CohereAPIKey=your_cohere_key
GroqAPIKey=your_groq_key
TavilyAPIKey=your_tavily_key
HuggingFaceAPIKey=your_huggingface_key
5. Run the Assistant
Bash
python Main.py
